### 🚀 Ongoing Projects

- **[Zenthra](https://github.com/kabirajpan/zenthra-v2)** `[Open Source]`  
  GPU-accelerated, cross-platform UI framework built from scratch in Rust with WebGPU (`wgpu`), WGSL shaders, and a custom subpixel text rendering pipeline (`cosmic-text`, `swash`).

- **[Zenthree](https://github.com/kabirajpan/zenthra-v2)**  
  Fast, native GPU-rendered code editor powered by Zenthra with Tree-sitter AST syntax highlighting, embedded PTY terminal, and an AI coding companion.

- **[Fly Decision Net](https://github.com/kabirajpan/fly-decision-net)** `[Research]`  
  Sub-millisecond NeuroAI decision engine for coding agents based on the 500-neuron *Drosophila melanogaster* connectome. Replaces slow cloud LLM routing with a local 50KB biological brain.

- **[After Motion](https://play.google.com/store/apps/details?id=com.aftermotion.app&pli=1)** `[Google Play]`  
  Mobile video editor and motion graphics app built with Kotlin Multiplatform (KMP), native Android, and a high-performance native core written in Rust.

- **[Zenthra Labs](https://zenthralabs.dev)**  
  Developer hub and ecosystem platform with an async Rust backend and edge-rendered web frontend.
